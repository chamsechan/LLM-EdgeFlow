# RFC 0047: 平台公共模拟声明隔离

- **RFC 编号**：0047-platform-mock-header-isolation
- **创建日期**：2026-09-10
- **文档状态**：Completed
- **关联分支**：`refactor/naming-and-header-boundaries`
- **目标版本**：v10.x
- **负责人 / 作者**：LLM-EdgeFlow Team
- **关联决策**：补充 RFC-0046 的头文件归属，遵守 RFC-0029 的外网与内网边界。

## 1. 问题与范围

当前公开接口将本项目实现的函数入口与供本地 Demo、Adapter 和测试使用的平台模拟声明
放在一起，容易把现有 `Company*` 数据结构和平台枚举误认为框架定义或真实公司 SDK。
用户明确要求将为当前环境模拟的公司公共定义单独归档。

本次只整理仓库已经存在的声明，不获取、推断或补写任何公司内部 SDK 契约。

## 2. 决策

- 新建 `include/platform_mock/`，集中保存 C ABI 业务类型及 DTO、错误码、Operator
  数据结构和 C++ 平台交互类型。头部与 README 明确其本地模拟用途。
- `include/edgeflow/` 继续持有本项目函数入口、框架辅助函数、日志、导出宏和版本。
  公开接口显式包含模拟声明，既有包含路径通过转发保持源码兼容。
- 保留所有类型名称、命名空间、枚举值、结构布局、默认值、函数签名和运行时行为。
- 模拟声明属于接入适配层的外部依赖；只对 SDK 消费方、Demo、Integration 和仓库测试
  可见。Core、Nodes、Models 和 Backends 继续禁止依赖这些声明。
- 内部业务 Result、Blackboard key、端口定义、I/O 池契约以及 Demo 读写结构保留原归属，
  不因名称包含业务或供 Demo 使用而归入平台模拟。

## 3. 迁移边界

该目录记录现有外网运行约定，不是公司 SDK 的接口复刻，也不承诺与真实平台二进制兼容。
进入授权内网后，依据实际公共定义替换接入边界的依赖并验证转换及 ABI；本次不增加
假定的 SDK 选择开关、下载规则或厂商依赖。

## 4. 验证与完成条件

- 新旧包含入口可同时编译，C 数据头独立通过 C11 检查，C++ 平台交互头独立可用。
- 复用现有 C ABI、Operator 契约及 Demo smoke，验证布局、枚举、函数表和运行结果。
- 实际 CMake include 参数及 LayerGuard 自测验证模拟头未传播到下层。
- 完整执行 `./scripts/run_all_tests.sh`；真实公司 SDK 与硬件验收不在此次范围内。
