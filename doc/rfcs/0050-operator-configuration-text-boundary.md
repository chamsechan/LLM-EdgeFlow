# RFC 0050: Operator 配置读取边界与普通参数结构

- **RFC 编号**：0050-operator-configuration-text-boundary
- **创建日期**：2026-09-11
- **文档状态**：Completed
- **关联分支**：`feat/operator-output-allocators`
- **目标版本**：v10.x
- **负责人 / 作者**：LLM-EdgeFlow contributors
- **关联决策**：补充 RFC-0049，替代其 JSON 参数回调和参数基类序列化要求

## 1. 问题与范围

RFC-0049 将队列与单份结构分配分开，但结构体作者仍须接收 `nlohmann::json`、
继承参数基类并实现 `ToJson()`。这使配置格式进入扩展接口，也增加了接入新结构的成本。
本次只调整接入适配层 / Integration 的创建阶段及配置检查工具，不新增业务 Pipeline Node。

## 2. 决策与权衡

- 配置读取是接入层独立组件，使用固定 `OutputConfigField` 枚举选择输出配置项，
  返回拥有自身存储的 `std::string`。JSON 实现将选中的值序列化为 JSON 文本，保留
  对象、数组、字符串等值的区别；不暴露 JSON 类型，也不接受任意 JSON 路径。
- `.conf` 文件仍只由最外层 resolver 读取。JSON reader 处理单个输出配置对象，
  其他配置载体可实现同一读取接口。结构体方案的参数回调仅接收自己的参数文本，
  不接收文件路径、整个部署配置或队列信息。
- 用 `MakeOutputParameterParser<T>(parse)` 将普通参数结构和字符串解析函数适配到
  框架。结构体作者不继承参数基类、不实现反向序列化；框架包装并共享不可变参数，
  分配、预算、重置和业务转换继续通过 `Parameters<T>()` 获取同一对象。
- 解析函数在创建阶段执行一次，负责自己的枚举、容量与默认值；可以采用适合该
  结构的解析方式。读取器负责载体提取，解析函数负责该结构的语义，两者都属于接入层。
- `resolve-conf` 的 `output_pools[*].params` 改为读取器产生的参数字符串，表示提交
  给解析函数的内容，不宣称它包含自定义解析器补齐的默认值。内置容量等框架字段
  继续展示解析后的值。未配置参数时 JSON reader 返回 `"{}"`。

文本边界允许结构体作者自行选择解析方式。采用 JSON 的方案会在配置提取和语义解析
之间多一次序列化/解析，但只发生在 Create，结果由所有输出块复用。工具展示原始
参数文本，使作者无需为每个结构编写仅供检查工具使用的反向序列化。

## 3. 兼容与迁移

既有 `.conf`、业务输出结构和公开 C ABI 不变。RFC-0049 新增的源码扩展参数回调
改用字符串，采用 helper 的参数类改为普通结构。单输出兼容字段 `output_pool` 与
对应 `output_pools` 项保持一致。该文本边界不决定最终业务输出格式。

## 4. 验证与完成条件

扩展现有 Operator 测试，验证固定枚举、缺省值、序列化与异常枚举；普通参数结构、
非 JSON 解析函数、错误隔离及类型检查；保留多输出、同键不同方案、配置只解析一次、
全部输出池分配失败回滚和无分配复用。运行相关 ASan/UBSan 与一次 canonical gate。

## 5. 实施与最终结果

已实现枚举读取接口、私有 JSON 读取器、字符串参数回调与普通参数结构 helper。
使用步骤见[输出分配指南](../dev_guide/operator_output_allocation.md)。

默认构建的五个 Operator 套件共 100 个用例通过。补充的真实 resolver 断言验证两个
handle、两个输出槽位分别保留原参数文本，具体参数结构正确补入自己的默认值。
`resolve-conf` 对旧 `mem_que`、新 `outputs` 及缺省/显式空参数返回字符串，单输出
兼容结果保持一致。

独立 Debug ASan/UBSan 构建开启泄漏检测，五个 Operator 套件通过：98 个用例通过，
两个 ONNX 场景因该构建关闭后端而跳过，并已由默认构建覆盖。未发现 sanitizer 或
泄漏报告；分配失败回滚、解析一次和无分配复用检查保持通过。

默认后端集、全部 CTest、格式与文档检查通过统一的 `./scripts/run_all_tests.sh`
门禁完成验证。本次不涉及真实公司 SDK 或新模型效果验收。
