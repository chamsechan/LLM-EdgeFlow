# Studio 操作验收

范围：单用户本机 Pipeline JSON 编辑、浏览与示例试运行。JSON 是唯一方案文档；
服务端临时 `.conf` 是运行适配细节，界面及保存 API 不管理部署关联。

## 交互目标

首次使用者应能独立完成“打开示例 → 修改关键词 → 试运行 → 核对输出 → 保存重开”。
常规修改自动更新，保存与运行合法性分开；高级 JSON 和模型配置按需打开。
自动化不能证明首次用户无需教程，仍需用上述任务观察用户的发现时间、犹豫与误操作。

## 操作路径与验收标准

| 任务 | 验收标准 |
| --- | --- |
| 首次进入 | 可见示例、打开 JSON 入口；空白创建保留在创建方式中 |
| 修改规则 | 节点可按 Catalog 类型与说明搜索；映射与规则列表无需手写 JSON；完成输入自动更新 |
| 输入未完成 | 保存、试运行切回并展开定位非法字段；可撤回当前输入且保留已完成修改；有未保存修改时离开页面前提示 |
| 重命名后保存 | 修改步骤标识后直接点击一次保存，等待重命名完成后保存新名称及更新后的引用 |
| 保存半成品 | 缺失连接或运行工具也可保存 JSON；文件名限定 `pipeline_[a-z0-9_]+.json`；同名冲突、外部修改、符号链接仍受保护 |
| 文件边界 | 保存仅写 JSON；旁边 `.conf` 的内容及变化不影响保存 |
| 连线 | 点击与拖放共用吸附规则；目标高亮、拖动时边缘平移、Esc 取消与键盘端口选择；缩小后端口不互相遮挡 |
| 复杂图 | 首次进入保持可读；全图概览、选中聚焦可切换；参数面板可调宽 |
| 撤销与修复 | 已完成修改可撤销重做；原生修复先预览，再整体应用和撤销 |
| 试运行 | 使用当前文档及所选数据；第一条命中新规则、第二条未命中；不完整方案拒绝执行 |
| 结果时效 | 修改后提示旧版本；切换方案隔离结果，旧任务仍可取消 |
| 未知配置 | 编辑已知字段不丢弃未知参数；定义不可用时保留高级 JSON 编辑 |

## 验证方式

- `tests/tooling/test_pipeline_studio.py` 覆盖 JSON 保存、结构错误、文件名规则、
  不依赖运行工具的半成品保存、执行前校验、并发保存、外部冲突、临时运行文件清理与取消/超时。
- `studio_editor_test.mjs`、`studio_graph_test.mjs`、`studio_config_roundtrip_test.mjs`、
  `studio_fix_workflow_test.mjs` 覆盖字段默认值、字符串保真、图几何、模型绑定与原生修复。
- 可选 `studio_browser_test.mjs` 使用真实关键词 Demo 检查自动更新、表单、节点搜索、
  重命名后一次保存、非法输入的定位与撤回、点击与拖放连接、概览缩放下的端口命中、
  半成品保存、外部修改冲突、修复预览、结果时效和复杂图阅读。
  在 1280×768、1366×768、1920×1080 检查关键操作可达与水平溢出，可保存截图人工核对。
- 浏览器组件使用本机已安装的 Playwright，不新增项目依赖。
- 边缘平移的连续手感、首次用户发现时间、触屏及超大图性能仍需要人工验收；
  关键词 Demo 成功不代表真实模型效果或目标硬件验收。
