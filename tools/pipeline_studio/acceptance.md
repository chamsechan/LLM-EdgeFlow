# Studio 操作验收

范围：单用户本机 Pipeline JSON 编辑、浏览、原生校验与保存。
JSON 是唯一方案文档，运行与资产验收使用独立 Demo 和检查工具。

## 交互目标

用户应能完成“打开或新建方案 → 修改参数与连线 → 检查并定位错误 → 保存重开”。
常规修改自动更新，半成品允许保存；复杂参数、模型配置和原始 JSON 按需打开。
自动化验证操作结果；首次用户发现时间与操作手感仍需人工观察。

## 操作路径与验收标准

| 任务 | 验收标准 |
| --- | --- |
| 首次进入 | 可打开已有 JSON，也可选择输入输出新建空草稿 |
| 修改规则 | 按 Catalog 搜索节点；基本字段、映射与规则列表可编辑；完成输入自动更新 |
| 输入未完成 | 保存或检查定位非法字段；可撤回当前输入；离开未保存文档前提示 |
| 重命名后保存 | 一次点击保存等待重命名完成，同时保留参数及更新后的引用 |
| 保存半成品 | 缺失连接或校验工具也可保存；保留未知字段和未显式设置的默认值 |
| 文件边界 | 仅写 JSON；拒绝同名覆盖、revision 冲突、路径逃逸和符号链接；旁边 `.conf` 不影响保存 |
| 连线 | 支持点击、拖放、删除、Esc 取消和键盘端口选择；最终合法性由原生工具判定 |
| 画布阅读 | 支持平移、缩放、全图概览、选中聚焦和自动布局；简单折线不保证避开全部节点 |
| 撤销 | 已完成的文档修改可撤销、重做；文本输入框保留自身快捷键 |
| 模型绑定 | 可编辑实例、Backend 和参数，重命名保持声明的绑定引用 |
| 校验 | 显示原生错误码、JSON Pointer、节点定位和建议；修改后旧报告失效 |

## 验证方式

- `tests/tooling/test_pipeline_studio.py` 覆盖 HTTP、I/O 草稿、原生编辑与诊断、文件事务和冲突。
- `studio_editor_test.mjs`、`studio_graph_test.mjs`、`studio_config_roundtrip_test.mjs`
  覆盖字段默认值、字符串保真、图几何和模型绑定。
- 可选 `studio_browser_test.mjs` 覆盖新建、打开、自动更新、节点搜索、重命名后一次保存、
  非法输入定位与撤回、点击与拖放连接、撤销重做、半成品保存、外部冲突和复杂图阅读。
  在 1280×768、1366×768、1920×1080 检查操作可达与水平溢出，可保存截图人工核对。
- 浏览器组件使用本机已有 Playwright，不新增项目依赖。
- 触屏、超大图性能、模型加载、业务效果和目标硬件需要独立验收。
